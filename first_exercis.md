# 1. How `create_project()` Works

The `create_project()` function first sets the paths of your Tcl script and Vivado log file. It checks whether the Tcl script exists. If it is missing, the function raises an error. It then creates the log folder if needed; if the folder already exists, execution continues normally.

Next, it launches Vivado in batch mode and asks Vivado to execute `build_project.tcl`. Your Tcl script handles opening or creating the project and adding the RTL, testbench, and constraint files.

Python waits until Vivado finishes and captures its console output. The function then returns a dictionary containing the exit code, log-file path, standard output, and standard error. It does not itself parse the log or decide whether warnings need fixing.

## How the Agent Uses `create_project()`

When connected to the agent, we describe `create_project()` as an available tool. The agent can request this tool when it needs to create or reopen the project. Our Python program executes the function and sends its returned dictionary back to the agent.

The agent can then request the log-parsing tool using the returned log path. Based on those messages, it decides whether to investigate an issue, request a permitted correction, or proceed toward behavioral simulation.

## Python Implementation

```python
import pathlib
import subprocess


def create_project():
    script_file = pathlib.Path(
        r"C:\Agents\Day2\scripts\build_project.tcl"
    )

    log_file = pathlib.Path(
        r"C:\Agents\Day2\logs\build_project.log"
    )

    if not script_file.is_file():
        raise FileNotFoundError(f"Missing Tcl script: {script_file}")

    log_file.parent.mkdir(parents=True, exist_ok=True)

    result = subprocess.run(
        [
            "vivado",
            "-mode", "batch",
            "-source", str(script_file),
            "-log", str(log_file),
        ],
        capture_output=True,
        text=True,
        errors="replace",
    )

    return {
        "exit_code": result.returncode,
        "log_file": str(log_file),
        "stdout": result.stdout,
        "stderr": result.stderr,
    }
```

# 2. The `summarize_vivado_log()` Function

The `summarize_vivado_log()` function reads the log generated by Vivado and converts its messages into a structured dictionary that the agent can inspect.

It identifies errors, critical warnings, warnings, and informational messages according to the selected filter. For each matching message, it extracts the severity, message ID, actual text, and line number.

It groups messages with the same severity and ID, then counts their occurrences. Each group includes a summary and one complete example. Recognized message patterns receive a short description; other messages retain their original text on a single line.

The `max_messages` argument limits the examples retained per severity in the `examples` list. It does not reduce the occurrence counts or remove the first example stored for each group.

## How the Agent Uses This Function

When connected to the agent, this function provides evidence for deciding the next action. For example, the agent can see that a warning concerns a duplicate file addition, inspect the relevant Tcl script, and decide whether a correction is needed.

The function itself does not fix files or decide whether simulation can proceed. It organizes the log information so the agent can make that decision.

## Python Implementation

```python
import pathlib


def summarize_vivado_log(log_file, filter="default", max_messages=None):
    severity_order = ["ERROR", "CRITICAL WARNING", "WARNING", "INFO"]

    filters = {
        "errors": ["ERROR"],
        "critical": ["CRITICAL WARNING"],
        "warnings": ["WARNING"],
        "info": ["INFO"],
        "all": severity_order,
        "default": ["ERROR", "CRITICAL WARNING", "WARNING"],
    }

    # Validate the requested filter and example limit.
    if not isinstance(filter, str) or filter not in filters:
        raise ValueError("Unsupported filter.")

    if max_messages is not None:
        if type(max_messages) is not int or max_messages < 0:
            raise ValueError(
                "max_messages must be a nonnegative integer or None."
            )

    selected = filters[filter]
    log_file = pathlib.Path(log_file)

    totals = {}
    grouped_messages = {}
    retained_counts = {}

    for severity in selected:
        totals[severity] = 0
        grouped_messages[severity] = {}
        retained_counts[severity] = 0

    examples = []
    omitted_examples = 0

    # Summarize recognized text patterns; preserve other messages.
    def summarize_message(text):
        single_line = " ".join(text.split())
        lower_text = single_line.lower()

        if (
            "cannot add board part" in lower_text
            and "either invalid or not available" in lower_text
        ):
            return (
                "Board definition cannot be added because its "
                "device part is invalid or unavailable."
            )

        if "boardpart property will be unset" in lower_text:
            return "Selected board part not found; BoardPart will be unset."

        if (
            "already exists in the project" in lower_text
            and "skipping this file" in lower_text
        ):
            return "File already exists; duplicate addition skipped."

        if lower_text.startswith("exiting vivado"):
            return "Vivado is exiting."

        return single_line

    # Read the file and retain original line numbers.
    with log_file.open(encoding="utf-8", errors="replace") as log:
        for line_number, line in enumerate(log, start=1):
            line = line.strip()

            severity = None
            text = ""

            for candidate in selected:
                prefix = candidate + ":"

                if line.startswith(prefix):
                    severity = candidate
                    text = line[len(prefix):].strip()
                    break

            # Ignore unrelated lines and unselected severities.
            if severity is None:
                continue

            message_id = "UNTAGGED"

            if text.startswith("["):
                closing_bracket = text.find("]")

                if closing_bracket > 1:
                    candidate_id = text[1:closing_bracket].strip()

                    if candidate_id:
                        message_id = candidate_id
                        text = text[closing_bracket + 1:].strip()

            totals[severity] += 1
            severity_groups = grouped_messages[severity]

            # Keep one full example per group for agent diagnosis.
            if message_id not in severity_groups:
                severity_groups[message_id] = {
                    "severity": severity,
                    "id": message_id,
                    "count": 0,
                    "summary": summarize_message(text),
                    "example": text,
                    "line_number": line_number,
                }

            severity_groups[message_id]["count"] += 1

            # Limit additional examples without limiting occurrence counts.
            if (
                max_messages is None
                or retained_counts[severity] < max_messages
            ):
                examples.append({
                    "severity": severity,
                    "id": message_id,
                    "text": text,
                    "line_number": line_number,
                })

                retained_counts[severity] += 1
            else:
                omitted_examples += 1

    # Arrange groups by severity and message ID.
    groups = []

    for severity in selected:
        for message_id in sorted(grouped_messages[severity]):
            groups.append(grouped_messages[severity][message_id])

    return {
        "totals": totals,
        "groups": groups,
        "examples": examples,
        "omitted_examples": omitted_examples,
    }


if __name__ == "__main__":
    summary = summarize_vivado_log(
        r"C:\Agents\Day2\logs\build_project.log",
        filter="all",
        max_messages=3,
    )

    print("Severity | Message ID | Count | Summary")

    for group in summary["groups"]:
        print(
            f"{group['severity']} | {group['id']} | "
            f"{group['count']} | {group['summary']}"
        )
```




# 3. The `read_project_script()` Function

The `read_project_script()` function reads the contents of `build_project.tcl` and returns them in a dictionary, along with the file path and number of lines. It first checks whether the file exists and raises an error if it is missing.

## How the Agent Uses This Function

The agent uses this function when it needs to investigate how the project was created. For example, if the log reports a duplicate file addition, the agent can request the script and inspect its `add_files` commands.

This function gives the agent access to the script’s contents. It does not execute or modify the script.

## Python Implementation

```python
import pathlib


def read_project_script():
    script_file = pathlib.Path(
        r"C:\Agents\Day2\scripts\build_project.tcl"
    )

    # Check that the Tcl script exists.
    if not script_file.is_file():
        raise FileNotFoundError(
            f"Missing Tcl script: {script_file}"
        )

    # Read the script without modifying it.
    content = script_file.read_text(encoding="utf-8")

    return {
        "script_file": str(script_file),
        "content": content,
        "line_count": len(content.splitlines()),
    }


if __name__ == "__main__":
    try:
        result = read_project_script()

        print("Script:", result["script_file"])
        print("Number of lines:", result["line_count"])
        print("---Script Content---")
        print(result["content"])

    except (OSError, UnicodeError) as error:
        print("Unable to read project script:", error)
```


#4. The edit_project_script() function applies a correction to build_project.tcl. The agent provides two arguments: old_text, which identifies the existing code, and new_text, which contains its replacement.

The function checks that the script exists and that old_text appears exactly once. If it is missing or appears multiple times, the function raises an error without changing the script.

Before editing, it saves a backup with a timestamp in its filename. It then replaces the matched text, preserves the script’s line-ending style, and returns the script path, backup path, and change details.

The agent decides what correction to request; this function performs the replacement. It does not check whether the new Tcl code is correct. After editing, the agent can request create_project() again and inspect the fresh log to verify the change.

import pathlib
import datetime


def edit_project_script(old_text, new_text):
    script_file = pathlib.Path(
        r"C:\Agents\Day2\scripts\build_project.tcl"
    )

    # Validate the replacement arguments.
    if not isinstance(old_text, str) or not old_text.strip():
        raise ValueError("old_text must be a nonempty string.")

    if not isinstance(new_text, str):
        raise ValueError("new_text must be a string.")

    if not script_file.is_file():
        raise FileNotFoundError(
            f"Missing Tcl script: {script_file}"
        )

    # Read original bytes so the backup preserves the original file.
    original_bytes = script_file.read_bytes()
    content = original_bytes.decode("utf-8")

    # Match the script's line endings.
    newline = "\r\n" if "\r\n" in content else "\n"

    old_text = old_text.replace("\r\n", "\n").replace("\n", newline)
    new_text = new_text.replace("\r\n", "\n").replace("\n", newline)

    if old_text == new_text:
        raise ValueError("The replacement would not change the script.")

    # Require exactly one match to avoid changing the wrong occurrence.
    matches = content.count(old_text)

    if matches == 0:
        raise ValueError("old_text was not found in the script.")

    if matches > 1:
        raise ValueError(
            "old_text matches multiple locations. "
            "Include more surrounding text to identify one location."
        )

    updated_content = content.replace(old_text, new_text, 1)

    # Preserve a separate backup before applying the edit.
    timestamp = datetime.datetime.now().strftime("%Y%m%d_%H%M%S_%f")
    backup_file = script_file.with_name(
        f"{script_file.name}.{timestamp}.bak"
    )

    backup_file.write_bytes(original_bytes)

    # Update only the fixed project-creation script.
    script_file.write_bytes(updated_content.encode("utf-8"))

    return {
        "changed": True,
        "script_file": str(script_file),
        "backup_file": str(backup_file),
        "old_text": old_text,
        "new_text": new_text,
    }
